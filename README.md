# 📅 Agendador de Horários | Appointment Scheduler

## 🇧🇷 Português

### 📌 Sobre o projeto

O **Agendador de Horários** é uma aplicação Back-End desenvolvida com **Java e Spring Boot**, criada com o objetivo de praticar e consolidar conhecimentos em desenvolvimento de APIs REST, Programação Orientada a Objetos e integração com banco de dados.

O projeto está sendo desenvolvido de forma incremental como parte dos meus estudos em desenvolvimento Back-End.

### 🚀 Tecnologias utilizadas

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* H2 Database
* Maven
* REST API
* Programação Orientada a Objetos

### ⚙️ Funcionalidades

* Cadastro de agendamentos
* Consulta de agendamentos
* Exclusão de agendamentos
* Integração com banco de dados H2
* Persistência de dados utilizando JPA/Hibernate

### 🏗️ Estrutura

O projeto utiliza uma estrutura baseada em aplicações Spring Boot, com separação de responsabilidades entre as diferentes camadas da aplicação.

### 💻 Como executar

#### Pré-requisitos

* Java JDK instalado
* Git instalado

#### Clone o repositório

```bash
git clone https://github.com/Lipecs0/agendador-horarios.git
```

Entre na pasta do projeto:

```bash
cd agendador-horarios
```

Execute a aplicação:

**Windows:**

```bash
mvnw.cmd spring-boot:run
```

**Linux/macOS:**

```bash
./mvnw spring-boot:run
```

O projeto utiliza o **H2 Database como banco de dados em memória**, facilitando a execução e os testes da aplicação sem a necessidade de configurar um banco de dados externo.

### 📚 Objetivo

Este projeto faz parte dos meus estudos em desenvolvimento Back-End e tem como objetivo colocar em prática conceitos de **Java, Spring Boot, APIs REST, banco de dados e boas práticas de desenvolvimento**.

### 🔗 Repositório

[GitHub - Agendador de Horários](https://github.com/Lipecs0/agendador-horarios)
